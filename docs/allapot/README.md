# Állapotnapló

Ez a napló a usernek szól. Emberi nyelven mondja el, hol tart a munka, mi jön, és mire vár tőle. A következő ügynöknek szóló részletek az átadóba kerülnek (`docs/atado/`), nem ide. (S76)

Szabályok:
- Minden munkamenet végén új lap készül, a kódolás előtti szakaszban is. (S77)
- A lap neve: `docs/allapot/<éééé-hh-nn>-<n>.md`, ahol `<n>` a napi munkamenet sorszáma.
- Kód, parancs, commit-hash és fájlútvonal nem kerül bele. A szakszót kerüld, vagy magyarázd meg.
- Igés, egyszerű mondatokkal írj. A döntést kérő pontnál hivatkozz a döntéskérésre (`docs/dontest-ker.md`, DK-azonosító).
- Ami nincs kész, azt is írd le. A szépítés hiba. (K1)

## Sablon

```markdown
# <dátum>, <n>. munkamenet

## Mire jutottunk
<egyszerű mondatok, szakszó nélkül vagy megmagyarázva>

## Mi jön
<a következő lépések, sorrendben>

## Mire vár tőled
<döntések és jóváhagyások, hivatkozással a döntéskérésre; ha nincs: „semmire”>
```
